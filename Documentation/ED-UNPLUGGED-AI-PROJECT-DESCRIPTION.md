# ED Unplugged AI (ED / JR)

## Project description

ED Unplugged AI, also referred to as ED or JR, is a developing,
modular personal AI platform intended to provide an adaptable assistant
that can help users think, learn, create, organize information, and
complete practical digital tasks.

The project direction emphasizes user control, local-first operation,
privacy-conscious design, modularity, and the ability to work across
supported devices and services.

## Project goals

- Provide a consistent AI assistant and user experience.
- Support local AI models where compatible hardware and software permit.
- Enable modular tools, memory, and workflow capabilities.
- Support integrations such as messaging interfaces and automation.
- Keep user data and configuration under user control wherever practical.
- Make the system understandable, maintainable, and extensible.

## Architecture and development direction

ED Unplugged AI is developed as a collection of software components.
Depending on the selected build and configuration, these may include
an application interface, local model runtime, assistant orchestration,
memory functions, integrations, and automation tools.

The exact capabilities available in a particular release depend on
its source code, configuration, installed dependencies, and connected
services. Planned capabilities are not represented as completed or
guaranteed features.
